# Localization (`1.6/Languages/`, `Scripts/`, `.steamworkshop/`)

English (`English/Keyed/XTS_UI.xml`, `XTS_` prefix) is the source of truth; every other language
derives from it via the `/translate` skill (`.claude/skills/translate/SKILL.md`: this mod's
translation surface, grounding domain and glossary) and is validated deterministically by
`python3 Scripts/check-translations.py [--strict]`, also a CI release gate. Generation passes run
only on explicit request; English text rules are in the root `CLAUDE.md`.

- **Shared toolkit (`l10n/` submodule):** the family-wide process, per-language references,
  cross-language lessons, Workshop conventions and the checker/refresh/smoke engines live in the
  `rimworld-l10n` repo (canonical checkout `~/dev/rimworld-l10n`), shared with the sibling mods
  (`../UniqueMeleeWeapons`, `../UniqueWeaponsUnbound`, `../PersonaWeaponsUnbound`,
  `../BetterTradersGuild`). The `Scripts/` files are thin per-repo config shims over its engines.
  If `l10n/` is empty, run `git submodule update --init`. Never edit `l10n/` in place here:
  mod-independent learnings go upstream in the canonical checkout, mod-specific ones (this mod's
  coined terms) go in the skill's glossary. Upstream ships semver tags (a major means this repo's
  shim or flow needs an edit); the pin moves only at release, at the start of a translation pass,
  or when a new major lands, never per upstream commit.
- **What the checker validates:** key and placeholder parity, `<!-- EN: ... -->` staleness
  comments, DefInjected paths, file hygiene, the Workshop title coupling, and the `[player text]`
  rules.
- **The DefInjected expected set is the checked-in sidecar `Scripts/expected-injections.json`**,
  regenerated by `python3 Scripts/refresh-translation-expectations.py`, which boots RimWorld on a
  pinned mod list through the L10nProbe dev mod (source `l10n/probe/`; build and deploy it only
  from the canonical checkout), then restores `ModsConfig.xml`. It refuses while the game is open.
  Currently empty, since the mod ships no Defs. Never hand-edit it; regenerate.
- **Probe DLC set:** the probe boots with Biotech active (`CANONICAL_ACTIVE_MODS` in the refresh
  script), and the checker's `REQUIRED_DLCS` rejects a sidecar generated without it, since gated
  defs would drop out of the dump and their shipped translations would turn illegal.
- **Workshop title coupling:** each language's `XTS_SettingsCategory` Keyed value is the localized
  Steam Workshop title and must equal line 1 of `.steamworkshop/Description/<Language>.txt`; always
  change the two together (English keeps `Xenogerm Trader Stock` in both).
- **The public language roster lives in `CONTRIBUTING.md`** and must move in the same commit as
  any language change.
